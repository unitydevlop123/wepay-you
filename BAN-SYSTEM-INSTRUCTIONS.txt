===============================================
📋 HOW TO BAN A USER IN FIREBASE:
===============================================

In your admin panel or Firebase, set ONE of these fields for the user:

Option 1: Set "banned" field to true
{
  "email": "user@example.com",
  "banned": true
}

Option 2: Set "status" to "banned"
{
  "email": "user@example.com",
  "status": "banned"
}

Option 3: Set "account_status" to "banned"
{
  "email": "user@example.com",
  "account_status": "banned"
}

The system checks all three, so use whichever your admin panel uses!
